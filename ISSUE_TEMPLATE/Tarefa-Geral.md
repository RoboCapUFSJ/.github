### ✅ 4. Definição de "Pronto" (DoD)
*Marque os itens obrigatórios para a sua área antes de solicitar a revisão:*

**🛠️ Mecânica**
- [ ] Arquivo .STEP exportado na pasta correta.
- [ ] Desenho técnico (PDF) com medidas básicas incluído.
- [ ] Foto/Print do projeto finalizado.

**⚡ Eletrônica**
- [ ] Esquemático atualizado no repositório.
- [ ] Pinagem (pinout) documentada no README.
- [ ] Lista de Materiais (BOM) atualizada.

**💻 Computação**
- [ ] Código comentado e sem "números mágicos".
- [ ] Testado em bancada ou simulação.
- [ ] Documentação da lógica no README local.

**🤝 Gestão / Diretoria**
- [ ] Cronograma atualizado.
- [ ] Documento oficializado e salvo na pasta correta.
