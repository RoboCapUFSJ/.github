# 🤖 RoboCap - CENTRO DE CONTROLE

Bem-vindos ao hub central da nossa equipe de robótica. Esta Organização no GitHub é a nossa **Fonte Única de Verdade**. Se não está aqui, não existe.

---

## 🏗️ Nossas Áreas
Estamos divididos em cinco equipes especializadas. Cada uma possui seu próprio espaço de trabalho:

*   **🛡️ Diretoria:** Estratégia, cronogramas e aprovações finais.
*   **💻 Computação:** Código do robô, lógica autônoma e visão computacional.
*   **⚡ Eletrônica:** Design de PCBs, diagramas de fiação e gestão de energia.
*   **🛠️ Mecânica:** Projetos 3D (CAD), montagem de hardware e fabricação.
*   **🤝 Gestão:** Cultura da equipe, integração de novos membros (onboarding) e operações.

---

## 🚦 Fluxo de Trabalho (As Regras de Ouro)

Para manter o robô no caminho certo, cada membro deve seguir estas três regras:

### 1. Sem Issue = Sem Trabalho
Toda e qualquer tarefa, por menor que seja, deve ter uma **Issue** (tarefa) aberta e atribuída a alguém.
- Quer projetar um suporte? Abra uma Issue.
- Quer corrigir um bug? Abra uma Issue.
- Verifique o [Quadro de Projetos](https://github.com/orgs/RoboCapUFSJ/projects/6/views/1) para ver o que precisa ser feito.

### 2. Use as Etiquetas (Labels)
Usamos o sistema **Categoria: Valor**. Sempre identifique suas tarefas corretamente:
- `Area: Mecânica` | `Area: Computação` | etc.
- `Prioridade: Alta` (Se o robô estiver quebrado ou parado agora)
- `Status: Em Andamento` (Enquanto você estiver trabalhando)

### 3. Definição de "Pronto" (Done)
Uma tarefa só é considerada finalizada quando:
1.  O trabalho foi enviado para a pasta correta (Código, CAD ou Documentação).
2.  Um print ou foto do resultado foi anexado à Issue.
3.  A Issue foi movida para **`Status: Revisão Solicitada`** e um Diretor foi marcado.
4.  Um Diretor aprova e fecha a Issue.
